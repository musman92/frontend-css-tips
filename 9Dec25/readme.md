# Modern Animated Login Form

A sleek, modern login form featuring smooth animations, glassmorphism effects, and interactive hover states.

## ✨ Features

- **Glassmorphism Design**: Semi-transparent login card with backdrop blur effects
- **Smooth Animations**: Fade-in entrance animation for the login card
- **Floating Background**: Animated floating circles for visual appeal
- **Interactive Elements**: Hover effects on inputs and buttons with scale transforms
- **Password Toggle**: Eye icon to show/hide password
- **Responsive Design**: Optimized for various screen sizes
- **Modern UI**: Clean, professional design with gradient backgrounds

## 🎨 Design Elements

- **Background**: Linear gradient from purple to blue
- **Login Card**: Semi-transparent white with blur effect
- **Animations**: CSS keyframes for floating circles and fade-in effects
- **Hover Effects**: Scale transforms and shadow enhancements
- **Typography**: Poppins font family for modern look

## 🚀 Technologies Used

- HTML5
- CSS3 (Animations, Flexbox, Backdrop-filter)
- JavaScript (Password toggle functionality)

## 📱 Responsive

The login form is fully responsive and works well on:
- Desktop computers
- Tablets
- Mobile devices

## 🎯 Key Animations

1. **Card Entrance**: Slides up from bottom with fade-in
2. **Floating Circles**: Continuous up-down movement with scale
3. **Input Focus**: Slight scale increase on focus
4. **Button Hover**: Scale up with enhanced shadow
5. **Password Toggle**: Smooth icon transitions

## 🔧 Customization

You can easily customize:
- Color scheme by changing gradient values
- Animation speeds by modifying duration values
- Blur intensity by adjusting backdrop-filter
- Circle positions and sizes in the floating animation
