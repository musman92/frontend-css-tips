# Travel Agency Hero Section - Day 11

A professional travel agency hero section with fixed location cards, dynamic trip details, and a prominent "Book Now" call-to-action button - all powered by pure CSS and JavaScript!

## 🎨 Features

- **Fixed Location Cards** - Cards positioned in the right corner (desktop) or bottom (mobile)
- **Dynamic Trip Details** - Complete trip information updates based on selected destination
- **Professional CTA Button** - Eye-catching "Book Now" button with hover animations
- **Trip Highlights** - Detailed itinerary points for each destination
- **Pricing Display** - Clear pricing information with "per person" labels
- **Trip Information Grid** - Duration, group size, rating, and flight inclusion details
- **Smooth Transitions** - Fluid animations between location changes
- **Responsive Design** - Adapts beautifully from desktop to mobile

## 🚀 How It Works

The travel agency section uses:
- **Fixed Card Positioning** - Cards stay in place instead of auto-scrolling
- **Data-Driven Content** - JavaScript objects store complete trip information
- **Dynamic DOM Updates** - Content changes instantly when cards are clicked
- **CSS Grid Layout** - Trip information displayed in responsive grid
- **Gradient Buttons** - Modern CTA button with hover effects
- **Glassmorphism Design** - Backdrop blur effects for modern aesthetics

## 💻 Usage

Simply open `index.html` in any modern web browser to see the travel agency hero section:

- **Click Location Cards**: Instantly switch between destinations
- **View Trip Details**: See complete pricing, duration, and highlights
- **Book Now Button**: Functional CTA button (currently shows alert)
- **Responsive Layout**: Cards move to bottom on mobile devices
- **Smooth Animations**: Professional transitions between locations
