# Netflix-Style Content Listing Page

A stunning, fully functional Netflix-style content listing page with authentic design, smooth animations, and interactive features - built with pure HTML, CSS, and JavaScript!

## 🎬 Features

- **Authentic Netflix Design** - Pixel-perfect recreation of Netflix's interface
- **Hero Section** - Dynamic hero banner with Stranger Things branding
- **Content Rows** - Three categorized content sections (Trending Now, Popular on Netflix, Action Movies)
- **Interactive Cards** - 18 movie/TV show cards with hover effects and metadata
- **Smooth Scrolling** - Horizontal scrolling through content with arrow navigation
- **Circular Navigation** - Seamless infinite scrolling that wraps around
- **Pagination Dots** - Netflix-style dot indicators positioned inline with section titles
- **Responsive Design** - Adapts beautifully from desktop to mobile
- **Hover Animations** - Cards scale up with borders and shadows on hover
- **Professional Typography** - Netflix Sans font for authentic branding
- **Dark Theme** - Netflix's signature dark color scheme

## 🎨 Design Elements

### 🎯 **Navigation & Header**
- Netflix logo and navigation menu
- User profile indicator
- Smooth scroll-based header effects

### 🎪 **Hero Section**
- Large background image with gradient overlay
- Prominent title and description text
- Dual call-to-action buttons (Play & More Info)
- Responsive text sizing

### 🎭 **Content Cards**
- High-quality movie/TV show posters
- Hover overlay with title, rating, duration, and genre
- Play and More Info buttons
- Smooth scaling animations with border highlights

### 🎮 **Interactive Features**
- Left/Right arrow navigation for each row
- Clickable pagination dots for direct navigation
- Circular scrolling (wraps from end to beginning)
- Active dot indicators showing current position

## 🚀 Technical Implementation

Built with modern web technologies:

- **HTML5** - Semantic structure with proper accessibility
- **CSS3** - Advanced animations, gradients, and responsive design
- **Vanilla JavaScript** - Smooth scrolling, dot navigation, and interactions
- **Tailwind CSS** - Utility-first styling framework
- **Google Fonts** - Netflix Sans typography
- **Unsplash API** - High-quality, working images for all content

### Key CSS Features:
- `transform: scale()` for card hover effects
- `scroll-behavior: smooth` for fluid navigation
- `background: linear-gradient()` for overlays and effects
- `box-shadow` for depth and visual hierarchy
- `@media queries` for responsive breakpoints

### JavaScript Functionality:
- `scrollRow()` - Handles arrow navigation with circular wrapping
- `scrollToPage()` - Direct navigation via pagination dots
- `updateDots()` - Maintains active dot state during scrolling
- Event listeners for scroll synchronization

## 📱 Responsive Design

- **Desktop**: Full Netflix experience with all features
- **Tablet**: Adapted layout with maintained functionality
- **Mobile**: Hidden dots, stacked layout, touch-friendly interactions

## 🎯 Usage

Simply open `index.html` in any modern web browser to experience the full Netflix-style interface!
