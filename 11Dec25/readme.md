# DriveEasy - Modern Car Rental Landing Page

A stunning, modern landing page for a car rental company built with Tailwind CSS and smooth animations.

## ✨ Features

### 🚀 Above-the-Fold Hero Section
- **Gradient background** with animated floating elements
- **Animated text** with staggered fade-in effects
- **Call-to-action buttons** with hover animations
- **Statistics display** showing company credibility
- **Scroll indicator** with bounce animation

### 🛡️ Trust and Authority Section
- **Trust badges** with icon animations
- **Partner logos** display
- **Service guarantees** (24/7 support, full insurance, etc.)
- **Award recognition** indicators

### 🚗 Fleet Overview
- **Interactive category tabs** for different car types
- **Car cards** with hover lift effects
- **Detailed specifications** (seats, transmission, fuel type)
- **Dynamic pricing** display
- **Availability status** badges

### 📋 How It Works Section
- **3-step process** visualization
- **Animated step numbers** with hover scaling
- **Connected flow** with visual progress lines
- **Clear action icons** for each step

### ⭐ Social Proof and Reviews
- **Customer testimonials** with 5-star ratings
- **Profile avatars** with gradient backgrounds
- **Trust metrics** (customer count, uptime, etc.)
- **Animated review cards** on scroll

### 📍 Location and Contact Information
- **Multiple contact methods** with icons
- **Location grid** showing service areas
- **Quick contact form** with validation styling
- **Interactive map placeholder**

### 🔗 Footer
- **Company information** and social links
- **Quick navigation** links
- **Newsletter subscription** form
- **Legal links** and copyright
