# Cyberpunk Profile Card - Day 15

A futuristic cyberpunk-style profile card with glassmorphism effects, floating animations, and interactive hover states - created with pure CSS!

## 🎨 Features

- **Glassmorphism Design** - Semi-transparent card with backdrop blur effects
- **Floating Animation** - Subtle up-and-down floating motion
- **Spinning Glow Background** - Animated rotating gradient background
- **Interactive Hover Effects** - Scale transforms and enhanced glow on hover
- **Cyberpunk Color Scheme** - Cyan and blue gradient theme
- **Social Media Icons** - FontAwesome icons with hover animations
- **Responsive Design** - Adapts beautifully to all screen sizes
- **Modern Typography** - Clean Poppins font with proper hierarchy

## 🚀 How It Works

The cyberpunk card uses:
- **Glassmorphism Effects** - `backdrop-filter: blur()` for modern glass look
- **CSS Animations** - `@keyframes` for floating and rotation effects
- **Gradient Backgrounds** - Linear gradients for cyberpunk aesthetics
- **Transform Effects** - Scale and rotate transforms on hover
- **Box Shadow Glow** - Animated shadows for enhanced visual impact
- **FontAwesome Icons** - Professional social media icon integration

## 💻 Usage

Simply open `index.html` in any modern web browser to see the cyberpunk profile card:

- **Hover Effects**: Card scales up with enhanced glow
- **Floating Animation**: Continuous subtle floating motion
- **Spinning Background**: Animated gradient rotation
- **Social Links**: Interactive social media icons
- **Responsive Layout**: Adapts to all screen sizes

## 🎨 Design Elements

### **Visual Effects:**
- Semi-transparent card background (`rgba(255, 255, 255, 0.05)`)
- Backdrop blur filter for glassmorphism
- Animated cyan/blue gradient borders
- Spinning background glow effect
- Floating animation (3s ease-in-out)

### **Interactive Elements:**
- Card hover: Scale up (1.05x) with enhanced shadow
- Avatar hover: Scale and slight rotation
- Social icons: Color change and upward movement
- Button hover: Scale effect with glow

### **Typography:**
- **Poppins Font** - Modern, clean typography
- **White text** on dark background
- **Proper hierarchy** - Name, title, and description
