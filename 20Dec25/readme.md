# Flexbox Visual Playground - Day 20

An interactive CSS Flexbox learning tool that allows you to experiment with different flexbox properties and see the results in real-time with a visual grid background!

## 🎨 Features

- **Interactive Controls** - Radio button groups for all major flexbox properties
- **Real-time Updates** - See changes instantly as you modify properties
- **Visual Grid Background** - Grid overlay helps visualize spacing and alignment
- **Dynamic Axis Labels** - Cross-axis labels update based on flex-direction
- **Four Flexbox Items** - Numbered items to clearly show positioning effects
- **Clean UI** - Modern design with grouped controls and smooth transitions
- **Educational Tool** - Perfect for learning and teaching flexbox concepts

## 🧩 Flexbox Properties Covered

### 📐 **flex-direction**
- **row** - Items flow left to right (default)
- **row-reverse** - Items flow right to left  
- **column** - Items flow top to bottom
- **column-reverse** - Items flow bottom to top

### 🎯 **justify-content** (Main Axis)
- **flex-start** - Items align to start of main axis
- **center** - Items center on main axis
- **space-between** - Equal space between items
- **space-around** - Equal space around each item
- **space-evenly** - Equal space between and around items

### ⚖️ **align-items** (Cross Axis)
- **flex-start** - Items align to start of cross axis
- **center** - Items center on cross axis
- **flex-end** - Items align to end of cross axis
- **stretch** - Items stretch to fill container

## 🚀 How It Works

The playground uses:
- **Radio Button Controls** - Grouped inputs for each flexbox property
- **JavaScript Event Listeners** - Updates flex container styles in real-time
- **Dynamic Item Sizing** - Items adjust size based on stretch behavior
- **CSS Grid Background** - Visual grid helps understand spacing
- **Cross-axis Labels** - Dynamic labels show height vs width based on direction
