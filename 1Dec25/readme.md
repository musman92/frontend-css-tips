# Cyberpunk Product Card - Day 16

A futuristic cyberpunk-style product card with glowing effects, hover animations, and modern glassmorphism design - created with pure CSS!

## 🎨 Features

- **Cyberpunk Aesthetics** - Dark theme with cyan glow effects
- **Interactive Hover Animations** - Card lift, scale, and enhanced glow on hover
- **Image Zoom Effect** - Product image scales on card hover
- **Glowing Borders** - Animated cyan border with box-shadow effects
- **Modern Typography** - Clean Poppins font with proper hierarchy
- **Responsive Design** - Adapts beautifully to all screen sizes
- **Smooth Transitions** - Professional 0.35s ease transitions
- **Glassmorphism Elements** - Subtle transparency and blur effects

## 🚀 How It Works

The cyberpunk card uses:
- **CSS Transforms** - `translateY()` and `scale()` for hover effects
- **Box Shadow Glow** - Multiple layered shadows for depth
- **Image Transform** - Scale effect on hover for visual interest
- **Border Animations** - Color transitions and glow effects
- **Modern CSS** - Flexbox layout and smooth transitions
- **Color Scheme** - Dark background with cyan accent colors

## 💻 Usage

Simply open `index.html` in any modern web browser to see the cyberpunk product card:

- **Hover Effects**: Card lifts up with enhanced glow and scaling
- **Image Animation**: Product image zooms in smoothly
- **Glow Effects**: Cyan border and shadow animations
- **Responsive Layout**: Adapts to all screen sizes

## 🎨 Design Elements

### **Visual Effects:**
- Dark background (`#0d0d0d`) with card background (`#111`)
- Cyan glowing border (`rgba(0,255,255,0.4)`)
- Multi-layered box shadows for depth
- Smooth hover transitions (0.35s ease)

### **Interactive Elements:**
- Card hover: Lifts up (-8px) and scales (1.03x)
- Enhanced glow: Increased shadow intensity
- Image hover: Scales up (1.1x) within container
- Border color: Maintains cyan glow theme

### **Typography:**
- **Poppins Font** - Modern, clean typography
- **White text** on dark background
- **Proper hierarchy** - Product name, description, and price

### **Layout:**
- **Centered Design** - Flexbox centering on page
- **Card Dimensions** - 260px width with 20px padding
- **Border Radius** - 18px for modern rounded corners
- **Image Container** - Rounded 12px corners
