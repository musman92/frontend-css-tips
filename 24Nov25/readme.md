# CSS Multi-Layer Text Animation - Day 10

A stunning multi-layered text animation created with pure CSS - no JavaScript required! This project demonstrates advanced CSS animation techniques with multiple text layers, gradient colors, and complex transform effects.

## 🎨 Features

- **Pure CSS Animation** - No JavaScript dependencies
- **Multi-Layer Effect** - 5 overlapping text layers with different animations
- **Gradient Text** - Animated rainbow gradient background-clip text
- **Complex Transforms** - Scale, rotate, skew, and translate animations
- **Staggered Timing** - Each layer animates with different delays
- **Responsive Design** - Adapts beautifully to all screen sizes
- **Performance Optimized** - Hardware-accelerated animations

## 🚀 How It Works

The animation uses:
- **5 Text Layers** - Each with unique animation patterns
- **CSS Transforms** - Scale, rotate, skew, and translate effects
- **Background-Clip** - Gradient text with animated colors
- **Staggered Keyframes** - Different animation delays for depth
- **Opacity Layers** - Creating depth with transparency
- **Filter Effects** - Subtle blur effects for realism

## 💻 Usage

Simply open `index.html` in any modern web browser to see the multi-layered text animation in action. The text will continuously animate with flowing colors and dynamic movements.
