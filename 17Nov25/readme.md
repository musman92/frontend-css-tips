# CSS Image Hover Effect - Day 5

A smooth image hover effect created with pure CSS transitions - no JavaScript required! This project demonstrates how to create beautiful image reveal animations using CSS filters, transforms, and transitions.

## 🎨 Features

- **Pure CSS Animation** - No JavaScript dependencies
- **Smooth Transitions** - 0.8s ease transition for fluid animation
- **Blur to Clear Effect** - Dramatic blur reduction on hover
- **Scale Animation** - Subtle zoom out effect on hover
- **Brightness Adjustment** - Enhanced visibility with brightness filter
- **Responsive Design** - Works on all screen sizes

## 🚀 How It Works

The animation uses:
- `filter: blur()` and `brightness()` for visual effects
- `transform: scale()` for zoom transitions
- `transition: all 0.8s ease` for smooth animations
- `:hover` pseudo-class for interaction triggers
- `overflow: hidden` to contain the scaled image

## 💻 Usage

Simply open `index.html` in any modern web browser to see the image hover effect in action. Hover over the image to see the smooth blur-to-clear and scale transitions.
