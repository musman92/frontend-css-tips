# CSS Position Interactive Visual Demo - Day 20.1

An interactive learning tool that demonstrates all CSS position properties with real-time visual feedback! Perfect for understanding how static, relative, absolute, fixed, and sticky positioning work in CSS.

## 🎨 Features

- **Interactive Controls** - Radio buttons to switch between all position values
- **Real-time Positioning** - See immediate visual changes as you adjust properties
- **Dynamic X/Y Inputs** - Live adjustment of top/left values for absolute and fixed
- **Visual Containers** - Parent and viewport containers clearly labeled
- **Sticky Scroll Demo** - Dedicated scrollable area for testing sticky positioning
- **Informational Feedback** - Clear explanations for each position behavior
- **Modern UI** - Clean dark theme with smooth transitions

## 🧩 CSS Position Properties Covered

### 📍 **static**
- **Default behavior** - Elements flow in normal document order
- **No positioning** - top, left, right, bottom properties don't apply
- **Space preserved** - Other elements flow around as normal

### 🔄 **relative**
- **Offset from original** - Moves from its natural position
- **Space maintained** - Original space in document flow is preserved
- **Reference point** - Creates positioning context for child elements

### 🎯 **absolute**
- **Removed from flow** - No longer affects other elements' positions
- **Parent relative** - Positioned relative to nearest positioned ancestor
- **Interactive controls** - Live X/Y adjustment with number inputs
- **No space reserved** - Other elements fill the gap

### 📌 **fixed**
- **Viewport relative** - Positioned relative to the browser window
- **Scroll independent** - Stays in same position when scrolling
- **Interactive controls** - Live X/Y adjustment with number inputs
- **Always visible** - Perfect for navigation or floating elements

### 🏔️ **sticky**
- **Hybrid behavior** - Starts as relative, becomes fixed at threshold
- **Scroll triggered** - Switches to fixed when reaching specified position
- **Dedicated demo** - Scrollable container to test sticky behavior
- **Top threshold** - Sticks when reaching 10px from container top

## 🚀 How It Works

The demo uses:
- **Radio Button Controls** - Switch between all position values instantly

- **Multiple Containers** - Separate staging areas for different position types
- **Visual Labels** - Container boundaries clearly marked with labels
- **Smooth Transitions** - CSS transitions for smooth property changes

## 🖼️ Visual Elements

### 📦 **Container Structure:**
- **Viewport** - The main browser window (shown with border)
- **Parent Container** - Relative positioned container (blue dashed border)
- **Demo Box** - The element being positioned (green box with "BOX" text)
- **Sticky Area** - Scrollable container for sticky demonstration

### 🎛️ **Interactive Controls:**
- **Position Selector** - Radio buttons for all position values
- **X/Y Inputs** - Number inputs for absolute and fixed positioning
- **Live Feedback** - Descriptive text explaining current behavior

## 💻 Usage

Simply open `index.html` in any modern web browser and:

1. **Select a position** - Click any radio button to see the effect
2. **Adjust coordinates** - Use X/Y inputs for absolute and fixed positions
3. **Test sticky** - Scroll in the sticky area to see the sticking effect
4. **Read feedback** - Check the info text to understand each behavior
