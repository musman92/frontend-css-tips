# CSS Units Visual Demo

An interactive educational tool that visually demonstrates different CSS units and how they behave in real-time. This project helps developers understand the differences between absolute units (px), relative units (%, rem, em), and viewport units (vh, vw).

## 🎨 Features

- **Interactive Slider Control** - Adjust root font-size to see rem units in action
- **Visual Comparison** - Six different unit types displayed simultaneously
- **Real-Time Updates** - See changes instantly as you modify the root font-size
- **Color-Coded Elements** - Each unit type has a unique color for easy identification
- **Responsive Design** - Demonstrates how different units respond to viewport changes
- **Educational Interface** - Clean, focused design for effective learning

## 🧩 CSS Units Covered

### 📏 **Absolute Units**
- **px (pixels)** - Fixed size that doesn't change (150px - Red)

### 🔄 **Relative Units**
- **% (percentage)** - Relative to parent container (50% - Blue)
- **rem (root em)** - Relative to root font-size (10rem - Green)
- **em** - Relative to parent element font-size (1.5em - Green)

### 🖥️ **Viewport Units**
- **vw (viewport width)** - Relative to viewport width (30vw - Orange)
- **vh (viewport height)** - Relative to viewport height (20vh - Purple)

## 🎯 Learning Objectives

Understanding how different units behave:
- **Fixed vs Responsive** - How px stays fixed while other units adapt
- **Root vs Parent** - Difference between rem (root-relative) and em (parent-relative)
- **Viewport Responsiveness** - How vh/vw units respond to screen size changes
- **Practical Applications** - When to use each unit type in real projects

## 🚀 How It Works

The demo includes:
- **Interactive Slider** - Controls root font-size from 10px to 30px
- **Real-Time Display** - Shows current root font-size value
- **Visual Elements** - Six colored boxes demonstrating each unit type
- **Immediate Feedback** - Only rem units change with slider (as expected)
- **JavaScript Integration** - Updates CSS custom properties dynamically

## 🎨 Visual Design

- **Color Scheme**: 
  - Red: px (absolute)
  - Blue: % (percentage)
  - Green: rem/em (font-relative)
  - Orange: vw (viewport width)
  - Purple: vh (viewport height)
- **Layout**: Clean container with dashed border for clear unit comparison
- **Responsive**: Adapts beautifully to different screen sizes

## 💻 Usage

1. Open `index.html` in any modern web browser
2. Use the slider to adjust the root font-size
3. Observe how only the **rem** unit changes size
4. Resize your browser window to see how **vh** and **vw** units respond
5. Compare the behavior of different unit types
