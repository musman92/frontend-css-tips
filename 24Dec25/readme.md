# Product Hover Slider - Interactive Showcase

A modern, interactive product slider that expands on hover with a sleek flex-based layout. Perfect for e-commerce showcases, portfolio displays, or product galleries where you want to draw user attention dynamically!

## 🎨 Features

- **Flex-Based Responsive Layout** - Smooth transitions using CSS flexbox
- **Interactive Hover Effects** - Cards expand on hover to 3x their original width
- **Animated Title Rotation** - Product titles rotate from vertical to horizontal on hover
- **Smooth Details Animation** - Product details fade in and slide up with hover
- **Centered Slider Display** - 80% width, 500px height, perfectly centered on screen
- **Product Information** - Displays product names, prices, and call-to-action buttons
- **Gradient Overlay** - Dark overlay improves text readability over images
- **Smooth Transitions** - 0.6s ease transitions for professional feel

## 🧩 Components

### 📦 **Slider Container**
- **Layout**: Flex container with equal-width cards
- **Dimensions**: 80% of screen width, 500px height, centered
- **Spacing**: Cards distribute evenly and expand on interaction

### 🎴 **Product Cards**
- **Base State**: Equal flex portions (flex: 1)
- **Hover State**: Expands to 3x width (flex: 3)
- **Images**: Full background coverage with object-fit
- **Overlay**: Semi-transparent gradient for text visibility

### ✨ **Content Overlay**
- **Title**: Vertical text that rotates to horizontal on hover
- **Price**: Appears with fade-in animation
- **Button**: "Buy Now" CTA with hover color change
- **Animation Timing**: Coordinated 0.6s transitions

## 🎯 Interactive Elements

### Title Animation
- **Default**: Rotated -90deg at bottom
- **On Hover**: Rotates to 0deg, moves up with smooth transition
- **Effect**: Creates dynamic attention-grabbing movement

### Details Animation
- **Default**: Opacity 0, translated down 20px
- **On Hover**: Opacity 1, centered position
- **Effect**: Smooth fade-in and slide-up motion

### Button Interaction
- **Default State**: Orange (#ff6b00)
- **Hover State**: Lighter orange (#ff8c32)
- **Feedback**: Instant color change for user engagement

## 🚀 How It Works

The slider uses:
- **Flexbox Layout** - Dynamic resizing based on flex values
- **CSS Transitions** - Smooth 0.6s animations for all state changes
- **Transform Functions** - Rotation and translation for text effects
- **Absolute Positioning** - Content layering within cards
- **Gradient Overlays** - Enhanced readability and visual depth
