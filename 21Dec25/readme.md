# CSS z-index Interactive Demo - Day 21

An interactive educational tool that helps you understand how CSS `z-index` and `position` properties work together to control element stacking order.

## 🎨 Features

- **Interactive Controls** - Input fields and dropdowns for real-time property changes
- **Three Colored Boxes** - Red, Blue, and Green boxes for clear visual demonstration
- **Live Updates** - See changes instantly as you modify z-index and position values
- **Educational Interface** - Simple, clean design focused on learning
- **Overlapping Layout** - Boxes positioned to overlap for clear stacking visualization
- **Multiple Position Values** - Test static, relative, and absolute positioning

## 🧩 CSS Properties Covered

### 🔢 **z-index**
- Controls stacking order of positioned elements
- Higher values appear on top
- Only works with positioned elements (not static)
- Default value starts from 1, 2, 3 for the three boxes

### 📍 **position**
- **static** - Default positioning, z-index has no effect
- **relative** - Element positioned relative to its normal position
- **absolute** - Element positioned relative to nearest positioned ancestor

## 🎯 Learning Objectives

Understanding the relationship between:
- **z-index values** - How higher numbers stack on top
- **Position context** - Why z-index only works with positioned elements
- **Stacking context** - How elements layer in 3D space
- **Visual feedback** - Immediate results when changing properties

## 🚀 How It Works

The demo includes:
- **Three Control Panels** - One for each colored box (Red, Blue, Green)
- **Number Inputs** - Adjust z-index values from any number
- **Position Dropdowns** - Switch between static, relative, and absolute
- **JavaScript Updates** - Real-time style changes using `updateBox()` function
- **Overlapping Layout** - Boxes positioned with top/left offsets for clear stacking
